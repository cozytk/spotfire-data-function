# Spotfire Python 데이터 함수 교안
{: .no_toc }

Spotfire의 기본 기능만으로는 **어렵거나, 되더라도 너무 번거로운** 작업을
Python 데이터 함수 몇 줄로 해결하는 방법을 다룹니다.
그리고 그 코드를 **생성형 AI에게 정확하게 얻어내는 방법**까지를 목표로 합니다.

## 이 교육의 목표

이 교육이 끝났을 때 여러분이 할 수 있게 되는 것은 **"pandas를 외우는 것"이 아닙니다.**

> **하고 싶은 작업을 정확하게 설명해서, 생성형 AI로부터 바로 쓸 수 있는 데이터 함수 코드를 얻어내고,
> 그 코드가 맞는지 스스로 검증하는 것.**

그래서 이 교안은 세 부분으로 되어 있습니다.

| 순서 | 파트 | 내용 |
|---|---|---|
| 1 | [**문법**](./syntax/) | 데이터 함수의 구조, 입력/출력 규칙, 타입 매핑, pandas 최소 문법 |
| 2 | [**AI 활용법**](./prompting/) | 원하는 코드를 얻는 프롬프트 작성법과 검증 체크리스트 |
| 3 | [**예제 24종**](./examples/) | 기본 기능으로는 어려운 실무 작업들 |

## 왜 데이터 함수인가

Spotfire는 시각화와 탐색에 매우 강한 도구입니다.
하지만 **데이터를 바꾸는 작업**에서는 분명한 한계가 있습니다.

| 하고 싶은 일 | Spotfire 기본 기능 | 데이터 함수 |
|---|---|---|
| 중복 행 제거 | **기능 없음** (계산 컬럼+필터로 우회) | `drop_duplicates()` 한 줄 |
| 컬럼 200개를 Long으로 변환 | Unpivot — 컬럼을 일일이 선택 | `melt()` 한 줄, 컬럼 수 무관 |
| 시간이 정확히 안 맞는 두 테이블 조인 | **불가능** (= 조인만 지원) | `merge_asof()` |
| 연속 9점이 중심선 한쪽 (SPC 룰) | **표현식으로 불가능** | `rolling().sum()` |
| 그룹별 회귀 기울기를 데이터로 | 추세선은 그려지지만 값은 못 꺼냄 | `np.polyfit()` |
| 통계 검정 (t-test, ANOVA) | 기본 제공 없음 | `scipy.stats` |
| 결측을 그룹 중앙값으로 대치 | 상수 대치만 가능 | `transform("median")` |

{: .참고 }
> 이 교안의 예제는 모두 **"Spotfire 기본 기능으로는 어렵거나 매우 번거롭지만,
> AI에게 코드를 받으면 5분 만에 끝나는"** 작업들로 골랐습니다.
> 반대로 Spotfire가 더 잘하는 일(필터링, 시각화, 마킹 연동)은 굳이 데이터 함수로 만들지 마세요.

## 진행 방식

```text
[1] 문법 파트를 훑는다          — 30~40분, 완벽히 외울 필요 없음
        ↓
[2] Level 1 예제를 직접 따라 한다 — 중복 제거 / 결측 처리 / 조인 후 분리
        ↓
[3] 프롬프트 파트를 읽는다        — '요구사항 → 코드'로 바꾸는 방법
        ↓
[4] Level 2~4 예제는 '먼저 프롬프트로 만들어 보고' 정답 코드와 비교한다
```

가장 중요한 것은 **4번**입니다.
예제 코드를 그냥 복사하지 말고, **프롬프트를 먼저 써서 AI에게 받아 본 뒤**
교안의 코드와 비교해 보세요. 차이가 나는 지점이 바로 여러분이 배워야 할 부분입니다.

## 실습 환경

| 항목 | 내용 |
|---|---|
| Spotfire | Analyst 10.7 이상 (네이티브 Python 데이터 함수 지원) |
| Python | Spotfire에 **번들된 인터프리터** 사용 (별도 설치 불필요) |
| 기본 패키지 | `pandas`, `numpy` — 이 교안 예제의 대부분이 이것만 사용합니다 |
| 추가 패키지 | `scipy`(18번), `scikit-learn`(22번), `matplotlib`(23번) — 설치 필요할 수 있음 |
| 실습 데이터 | [`data/` 폴더](https://github.com/cozytk/spotfire-data-function/tree/main/data)의 CSV 11종 |

## 실습 데이터

교육용으로 준비한 데이터입니다. 사내 실제 데이터가 아니라 **가상으로 만든 데이터**이며,
공개 데이터셋(titanic, iris, diabetes)도 함께 제공합니다.

| 파일 | 내용 | 주로 쓰이는 예제 |
|---|---|---|
| `fab_measurement.csv` | 공정 계측 이력 11,091행 (중복·결측·0값·이상치 포함) | 01~13, 20~23 |
| `lot_master.csv` | LOT 마스터 (제품/라인/우선순위) | 04 |
| `equipment_sensor_wide.csv` | 설비 센서 wide 포맷 (S001~S020) | 05, 14, 17 |
| `equipment_alarm_log.csv` | 설비 알람 로그 (텍스트 메시지) | 15, 16 |
| `wafer_yield.csv` | 웨이퍼별 수율/불량 유형 | 19 응용 |
| `hr_training.csv` | 임직원 교육 이수 현황 | 06 응용 |
| `sales_orders.csv` | 제품 수주/출하 이력 | 09 응용, 19 |
| `titanic.csv` / `iris.csv` / `diabetes_train.csv` | 공개 데이터셋 | 24 |

자세한 컬럼 설명은 [데이터셋 안내](./reference/datasets/)를 참고하세요.

{: .팁 }
> 데이터 함수는 **공정 엔지니어만의 도구가 아닙니다.**
> 품질(SPC·공정능력), 설비(알람·드리프트), SCM/영업(수주 파레토·리드타임),
> 경영지원(교육 이수 현황 피벗)까지 **표 형태 데이터를 다루는 모든 직무**에서 동일하게 쓰입니다.
> 예제 데이터도 그 범위를 고려해 구성했습니다.
