## 데이터 함수는 무엇인가

Spotfire 데이터 함수는 **"Spotfire 안에서 실행되는 Python 스크립트"** 입니다.

일반적인 Python 스크립트와 딱 두 가지가 다릅니다.

1. **입력 데이터를 파일에서 읽지 않습니다.** Spotfire가 변수에 미리 넣어 줍니다.
2. **결과를 파일로 저장하지 않습니다.** 특정 변수에 담아 두면 Spotfire가 가져갑니다.

```text
┌─────────────┐   ①입력 변수 생성    ┌──────────────┐   ②출력 변수 회수   ┌─────────────┐
│  Spotfire   │ ───────────────────▶ │   Python     │ ──────────────────▶│  Spotfire   │
│ 데이터 테이블 │   input = DataFrame  │   스크립트    │  output = DataFrame│  새 테이블/  │
│ 문서 속성    │                      │              │                    │  문서 속성   │
└─────────────┘                      └──────────────┘                    └─────────────┘
```

## 가장 단순한 데이터 함수

```python
import pandas as pd

df = input                     # Spotfire 가 넣어 준 데이터
df = df.drop_duplicates()      # 원하는 처리
output = df                    # Spotfire 가 가져갈 결과
```

이게 전부입니다. 중간의 처리 부분은 **평범한 pandas 코드**입니다.
그래서 인터넷·책·AI에서 얻은 pandas 코드를 **거의 그대로 쓸 수 있습니다.**

## 만드는 순서 (Spotfire 화면)

1. **데이터 > 데이터 함수 > 새 데이터 함수 등록** (또는 `도구 > 데이터 함수 등록`)
2. **스크립트** 탭 — 언어를 **Python** 으로 선택하고 코드를 붙여 넣기
3. **입력 파라미터** 탭 — 스크립트에서 쓴 이름(`input`)과 **똑같이** 추가, 타입 선택
4. **출력 파라미터** 탭 — 결과 변수 이름(`output`) 추가
5. **저장** → 이름 지정 (라이브러리에 저장하면 다른 분석에서도 재사용 가능)
6. **실행** → 각 파라미터를 실제 데이터 테이블/문서 속성에 연결 → **실행**

{: .주의 }
> **파라미터 이름은 스크립트의 변수명과 정확히 일치해야 합니다.**
> `input1` 이라고 등록해 놓고 스크립트에서 `input` 을 쓰면
> `NameError: name 'input' is not defined` 가 납니다. 초보자가 가장 많이 겪는 오류입니다.

## 입력·출력 변수 이름은 자유

`input` / `output` 은 그냥 관례입니다. 아래처럼 의미 있는 이름을 쓰는 편이 훨씬 좋습니다.

```python
import pandas as pd

df = pd.merge(measurement, lot_master, on="LOT_ID")
clean_data = df.dropna(subset=["THICKNESS"])
defect_summary = clean_data.groupby("EQP_ID", as_index=False)["IS_DEFECT"].count()
```

이 경우 등록할 파라미터는

- 입력: `measurement`(Table), `lot_master`(Table)
- 출력: `clean_data`(Table), `defect_summary`(Table)

{: .팁 }
> `input` 은 사실 **파이썬 내장 함수 이름**이기도 합니다.
> 데이터 함수 안에서는 문제가 안 되지만, 의미 있는 이름을 쓰는 습관이 코드 가독성에 훨씬 좋습니다.

## 입력과 출력은 여러 개 가능

개수 제한이 없습니다. 이것이 데이터 함수의 큰 장점입니다.

```python
import pandas as pd

df = pd.merge(input1, input2, on="JOIN_ID")

output1 = df[df["STEP_DESC"] == "PC"]
output2 = df[df["STEP_DESC"] == "RMG"]
output3 = df[~df["STEP_DESC"].isin(["PC", "RMG"])]
```

한 번 실행으로 **테이블 3개**가 만들어집니다.
Spotfire 기본 기능으로는 할 수 없는 일입니다. ([04번 예제](../../examples/04-join-and-split/))

## 스크립트 안에서 지켜야 할 것

| 규칙 | 이유 |
|---|---|
| `import` 는 스크립트 안에 직접 쓴다 | 매번 새로운 실행 환경에서 돌기 때문 |
| 파일 읽기/쓰기를 하지 않는다 | 서버(Web Player) 환경에는 그 경로가 없음 |
| 절대 경로를 하드코딩하지 않는다 | 다른 사용자 PC에서 깨짐 |
| 무한 루프·사용자 입력을 넣지 않는다 | Spotfire가 응답 없이 멈춤 |
| 출력 변수에 **반드시 값을 할당**한다 | 할당 안 하면 "출력 변수를 찾을 수 없음" 오류 |

## 실행 시점

데이터 함수는 다음 경우에 실행됩니다.

- 사용자가 **직접 실행**할 때 (데이터 > 데이터 함수 > 새로 고침)
- **"입력이 변경되면 자동으로 다시 계산"** 옵션이 켜져 있고, 연결된 입력이 바뀌었을 때
  (마킹 변경, 필터 변경, 문서 속성 변경)
- 분석 파일을 **열 때** (설정에 따라)

{: .팁 }
> 마킹이나 문서 속성 슬라이더와 연동하는 데이터 함수라면 **자동 재계산을 반드시 켜야** 합니다.
> 반대로 무거운 계산(수십만 행 클러스터링)은 자동 재계산을 **꺼 두고** 버튼으로 실행하게 하세요.
> 필터를 만질 때마다 30초씩 멈추는 대시보드가 됩니다.

## 정리

- 데이터 함수 = **입력 변수가 준비된 상태에서 실행되는 pandas 스크립트**
- 파라미터 이름 = 스크립트 변수 이름 (**정확히 일치**)
- 입력/출력 **개수 제한 없음**
- 파일 I/O 대신 **변수로 주고받는다**
